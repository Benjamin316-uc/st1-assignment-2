Part H: Reflection

What did you build before using AI?

Using the student handbook, I created a very simple system that takes variables and prints them in a pre-formatted string for the user. In order to add additional names and times, new variable must be created before the code is run. When run the system displays a clean but simple timesheet with the patients and practitioners name and time of appointment in a long string.

The enhanced version uses lists, dictionaries and functions to enhance the system. This allows for a lightly easier way to update the system however is still not idea or asthetic. 

The time in both cases is recorded as a string. 


What did AI help you understand?

The AI helped to clarify what the code does, it listed the functions and why they are used, told me the limitations of the code such as, no persistence, conflict checking, or input from the user. Then the AI suggested improvements to make to the code and auggested the introduction of a text or JSON file to save the data. The questions then helped me to think about how the system works and some issues that may come up if the system was to be used.

Overall, the AI made me question how good the system was whilst providing me with insights into how I can make improvements to the system. 


Did AI make assumptions?

The AI did make some positive assumptions. It assumed that the system would not be very useful if the patient name, practitioner name or time were empty.

How did you verify the AI output?

I verfied the AI outputs by changing selected parts of the code and running it to see how the response changed. I then noted this change down before testing other selected sections


What engineering work remained for you?

Some engineering work was required such as my input on a suggested change to the appointment time variable. Changing this to require a year-month-day hour-minutes-seconds input was necessary to esure the system runs correctly.
